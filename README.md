# Vet Clinic

A simple veterinary clinic management system built with JavaScript. This project aims to help clinics manage their pet records, appointments, and client information efficiently.

## Features

- Pet registration and tracking
- Client (pet owners) management
- Appointments scheduling
- Medical history for pets
- Easy-to-use JavaScript-based UI
- 100% JavaScript

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (if the project includes backend/server-side code)
- Modern web browser (if frontend only)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jocker18291/vet_clinic.git
   cd vet_clinic
   ```

2. (Optional) Install dependencies:
   ```bash
   npm install
   ```
   _Skip this if the project is frontend only and doesn’t need npm._

3. Open the `index.html` file in your browser, or run the app if it's Node-based.

### Usage

- Register new pets and their owners.
- Schedule, modify, or cancel appointments.
- View and update medical histories.
